# 要件定義書（requirements.md）

個人事業主・フリーランス向け「お金と税金の管理アプリ」（仮称：おかねと税金ノート）

## 1. 目的

日本の個人事業主・フリーランスが、日々の売上・経費を登録するだけで次のことを理解し、自分で判断できるようにする。

| # | 利用者が知りたいこと | 実装段階 |
|---|---|---|
| 1 | 今年の収入と経費はいくらか | 第1段階（概算入力）／第2段階（取引登録） |
| 2 | 今年の事業利益の見込み | 第1段階 |
| 3 | 今年の所得に対する所得税等の見込み | 第1段階（簡易）／第4段階（本実装） |
| 4 | 確定申告時にあといくら納税するか | 第1段階（簡易）／第4段階 |
| 5 | 翌年度の住民税・国民健康保険料などの見込み | 第1段階（簡易）／第5段階 |
| 6 | 利益から申告時の納税額を差し引いた計算上の残額 | 第1段階 |
| 7 | 収入が増えた場合の税負担・手取りの変化 | 第6段階 |
| 8 | 経費を使った場合の税負担の変化 | 第6段階 |
| 9 | 確定申告に必要な書類・情報の不足 | 第2段階以降 |

会計ソフトのように帳簿を作るだけではなく、**「税引き後にいくら残る計算か」を毎日確認できること**を最大の価値とする。

## 2. 基本方針

### 2-1. 税金は支払う時期で分けて表示する

税金や保険料を合算して「これだけ残しておきましょう」と表示しない。以下を別枠で表示する。

1. 申告時に精算する所得税・復興特別所得税（＋該当する場合の消費税）
2. 翌年度に支払う住民税
3. 翌年度に支払う国民健康保険料
4. 該当する場合の個人事業税・消費税
5. 利用者が任意で取り置きする金額（第5段階）

例：2026年分の所得 → 所得税は2027年3月の確定申告で精算、住民税・国保は2027年度（2027年6月〜）に負担。

### 2-2. 口座残高は管理しない

- 「今、銀行にいくらあるか」ではなく「今年の利益から申告時の納税額を差し引くといくら残るか」を中心にする。
- 「申告時の精算後の残額」と「翌年度の税金まで取り置いた場合の残額」を混同しない。
- どちらも**実際の現金残高や自由に使える現金ではない**ことを画面に明記する（ホーム画面に実装済み）。

### 2-3. AIに税額を推測させない

税額はテスト可能なプログラム（税金計算エンジン）で計算する。AIはレシート読み取り・勘定科目候補など、利用者が確認できる用途に限定する。

### 2-4. わからないことは決めない

公式資料で確認できない税制は推測で実装しない。未対応・未確認の項目は画面上で明示する（`/taxes` 画面の「税務ルールの確認状況」）。

## 3. 想定ユーザー

日本国内の個人事業主・フリーランス（一般的な事業所得のみ）。

- 会計・税金の知識が少ない
- レシートをため込む／手作業で管理している
- 確定申告の時期まで税額を知らない
- 税金を考えずにお金を使い、後から納税に困る
- 収入が増えたとき実際にいくら残るかわからない

## 4. 対応範囲（スコープ）

### 4-1. 初期版で対応する

- 事業所得のみの個人（白色・青色申告）
- 所得控除：社会保険料、小規模企業共済等掛金、生命保険料（控除額入力）、その他（控除額を直接入力）、基礎控除
- 源泉徴収税額・予定納税額の反映
- 住民税（標準税率）・国民健康保険料（利用者入力の料率）・個人事業税の概算
- 消費税：免税事業者、2割特例（税率10%の売上のみ）

### 4-2. 初期版では対応しない（画面で未対応と明示する）

| 項目 | 扱い |
|---|---|
| 給与所得・雑所得・不動産所得・譲渡所得など | 「該当あり」と回答した場合、税額は参考値である旨を警告 |
| 配偶者控除・扶養控除・医療費控除等の自動計算 | 控除額を直接入力してもらう |
| 純損失の繰越控除・損益通算 | 赤字は0円として扱い、警告 |
| 住民税の非課税判定・自治体ごとの超過課税 | 標準税率・課税として試算 |
| 国保の軽減（7割・5割・2割）・減免 | 未対応 |
| 消費税の一般課税・簡易課税 | 未対応（計算不可と表示） |
| 住宅ローン控除などの税額控除 | 未対応 |
| e-Tax 提出 | 第7段階以降に調査の上で実装。実装まで「提出済み」と表示しない |

## 5. 機能要件（全体）

開発指示書 4-1〜4-10 に対応。各機能の実装段階は `roadmap.md` を参照。

| ID | 機能 | 主な要件 |
|---|---|---|
| F-01 | 初期設定 | 段階的な質問。未入力項目の計算への影響を表示。暫定試算を許可 |
| F-02 | レシート読み取り | AI・OCRで読み取り→確認画面で修正→保存。推測で確定しない。重複警告。証憑と仕訳を関連付け |
| F-03 | 売上・入金 | 売上日と入金日を区別。源泉徴収税額。関連資料 |
| F-04 | 複式簿記・帳簿 | 勘定科目、仕訳（貸借一致を検証）、修正履歴、事業主貸・借、家事按分、固定資産・減価償却、総勘定元帳、試算表、損益計算書 |
| F-05 | ホーム・税金ダッシュボード | 売上・経費・利益（実績／予測）、税目別・年度別・納付時期別の税額、計算上の残額、警告 |
| F-06 | 年間の見込み | 既定は登録した金額のみで計算（自動の延長はしない）。利用者が年間の売上・経費の見込みを入力した場合はその金額で計算 |
| F-07 | シミュレーション | 変更前後の比較。経費の実質負担（例：10万円の備品で税3万円減→実質負担7万円）。減価償却の考慮。累進税率の誤解を与えない |
| F-08 | リスクチェック | 断定せず「何を確認すべきか」を説明 |
| F-09 | 確定申告書作成 | 年次締め、決算書、申告書の計算・PDF出力、履歴。対象外の場合は完成したように見せない |
| F-10 | e-Tax | 作成と提出は別機能。仕様調査後に実装 |

## 6. 非機能要件

- **スマートフォン最優先**（幅 360〜430px で快適に操作できること）。数字は等幅数字で見やすく表示。
- **金額は円単位の整数**。丸めは税務ルールに従って明示的に実装（`tax-engine.md`）。
- **セキュリティ**：Supabase RLS で本人のデータのみ参照可能。APIキー・秘密情報はブラウザに出さない。
- **再現性**：税額計算結果に、対象年度・計算日時・税務ルールのバージョン・入力条件・結果を保存。
- **監査性**：申告設定・仕訳・申告内容の変更履歴を保存。
- **品質**：税金計算の単体テスト・回帰テスト。国税庁の計算例・検証済みケースとの照合。公開前に税理士等の専門家レビュー。

| A-3 | 国保の料率・賦課限度額、子ども・子育て支援金分 | 参考値（特定の自治体の値ではない）。利用者の入力を前提 | 各自治体 |
| A-4 | 個人事業税の業種判定 | 利用者が税率を選択 | 都道府県税事務所 |

| A-7 | サービス名「おかねと税金ノート」 | 仮称 | 事業者 |
| A-8 | 料金プラン（月額500円・初月無料） | 案。課金機能は未実装 | 事業者 |
