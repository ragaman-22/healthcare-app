# 画面設計書（screens.md）

スマートフォン最優先（幅 360〜430px）。最大幅 `max-w-lg`（512px）で中央寄せし、PC でも同じレイアウトで表示する。

## 共通

- 上部ヘッダー：サービス名、デモモード表示
- 下部メニュー（固定）：ホーム／レシート／売上／税金／メニュー
- 数字は等幅数字（`.num`）、金額は「1,234,567円」形式、マイナスは「−」
- 予測・確定・納付済みはバッジで区別
- 警告は 3段階（重大＝赤、注意＝黄、情報＝灰）
- タップ領域は 44px 以上

## 1. ログイン・新規登録

- メールアドレス＋パスワード（新規登録は 8文字以上、注意事項への同意）
- 確認メールが必要な設定の場合は「確認メールを送信しました」と表示
- Supabase 未設定時は「デモモード」カード（サンプルデータで試す／初期設定から試す）
- 画面下部に「税額は試算」である旨を表示

## 2. 初期設定（9ステップ）

一度に大量の項目を見せず、1画面1テーマで質問する。すべての項目は「わからない」「空欄」で進められ、未入力時の影響を項目の下に表示する。

1. 申告する年と事業（申告対象年、屋号、業種、開業日）
2. 青色申告・白色申告（青色の場合は特別控除の区分）
3. お住まいとご本人（都道府県、市区町村、生年月日）
4. 家族と健康保険（配偶者、扶養人数、国保加入・人数、社会保険料）
5. その他の控除（生命保険料控除、小規模企業共済・iDeCo、その他）
6. 事業以外の収入と支払済みの税金（給与・その他所得の有無、源泉徴収税額、予定納税）
7. 消費税と個人事業税（課税区分、事業税率）
8. 今年のこれまでの売上・経費（概算・基準日）
9. 確認（主要項目の一覧、未入力項目と「暫定的な試算になる」旨）

保存後はホームへ。メニューからいつでも再編集できる（既存の値を初期表示）。

## 3. ホーム・税金ダッシュボード

上から順に、利用者が最も知りたい順で表示する。

1. **見出し**：「2026年分の見通し」「10月24日時点の入力にもとづく試算」
2. **計算上の残額カード**（最重要）
   - 大きな数字：今年の利益（年末予測）から今年分の所得税等を差し引いた額
   - 内訳：事業の利益 → 源泉徴収・予定納税 → 申告時の追加納付（還付）→ **申告時の精算後** → 翌年度の住民税・国保など → **来年の税金も取り置いた場合**
   - 注記：銀行残高・自由に使えるお金ではない
3. **売上・経費・利益**：現在までの実績と年末予測を並べた表、予測の精度バッジ、予測方法の説明
4. **確定申告で精算する税金**（2027年3月ごろ）：所得税等（年間）、追加納付／還付見込み、消費税、課税所得までの計算の要約
5. **翌年度に支払う税金・保険料**（2027年6月ごろ〜）：住民税、国保、個人事業税（それぞれ対象年度と納付時期の目安つき）
6. **確認が必要なこと**：未入力・未対応・精度に関する警告
7. **主な機能へのショートカット**
8. フッター：税務ルールのバージョン、計算日時

## 8. 税金の内訳と納付時期（`/taxes`）

- 所得税の計算過程（収入 → 経費 → 青色控除 → 事業所得 → 所得控除 → 課税所得 → 税額 → 申告納税額 → 第3期分）
- 累進税率の説明（境界を超えた部分だけ税率が上がる）
- 納付時期別の一覧
- **税務ルールの確認状況**（項目ごとに 確認済み／最終確認中／仮の値／未対応 と出典）

## 9. シミュレーション（第6段階の設計メモ）

- 入力：売上の増減、利益の増減、備品購入（10万・30万・50万円のプリセット）、控除の追加、青色控除の適用
- 表示：変更前／変更後／差額（所得、所得税等、住民税、国保、税負担合計、支出を含めた後の金額）
- 「経費を使えば得」という誤解を防ぐ表示：
  「10万円の備品を買うと税負担が約3万円減りますが、購入代金を含めた実質負担は約7万円です」
- 固定資産に当たる場合は「今年の経費になるのは減価償却費の分だけ」と表示し、購入額全額を経費として扱わない
