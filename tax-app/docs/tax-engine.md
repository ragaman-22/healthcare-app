# 税金計算エンジン設計書（tax-engine.md）

## 1. 方針

- 税金計算は AI による文章生成とは独立した、**テスト可能な純粋関数**として実装する（`src/lib/tax/`）。
- 対象年度ごとに税率・控除・適用条件を **税務ルール（`TaxRuleSet`）** として管理する（`src/lib/tax/rules/`）。
- 税目ごとにモジュールを分ける。
- 金額は円単位の整数。浮動小数の誤差を避けるため、率の掛け算は `multiplyRate`（10万分率の整数に直して計算）を使う。
- **公式資料で確認できない項目は推測で実装しない**。各ルール項目に確認状況を持たせ、画面に表示する。

### 確認状況（`VerificationStatus`）

| 値 | 意味 | 画面表示 |
|---|---|---|
| `verified` | 国税庁・自治体などの公式資料で確認済み | 公式資料で確認済み |
| `secondary_source` | 民間の解説資料等では確認したが、公式資料での最終確認が未了 | 公式資料で最終確認中 |
| `unverified` | 仮の値（自治体ごとに異なる等） | 仮の値 |
| `not_implemented` | 未対応（計算に含めていない） | 未対応 |

ルールのバージョンに `provisional` を含む年度は、ホーム画面に「税務ルールは確認中」と表示する。

## 3. 所得税（`calcIncomeTax`）

```
収入金額 − 必要経費 = 青色申告特別控除前の所得（profit）
青色申告特別控除 = min(控除額, profit)        ※ profit ≤ 0 なら 0
事業所得 = max(0, profit − 青色申告特別控除)    ※ 赤字は 0（繰越・損益通算は未対応）
合計所得金額 = 事業所得                         ※ 他の所得は未対応
基礎控除 = 区分表（合計所得金額で判定）
所得控除合計 = 社会保険料 + 小規模企業共済等掛金 + 生命保険料控除 + その他 + 基礎控除
課税所得 = max(0, 合計所得 − 所得控除合計) を 1,000円未満切捨て
基準所得税額 = 課税所得 × 税率 − 速算表の控除額（1円未満切捨て）
復興特別所得税 = 基準所得税額 × 2.1%（1円未満切捨て）
所得税及び復興特別所得税 = 基準所得税額 + 復興特別所得税
申告納税額 = 上記 − 源泉徴収税額
             → 納付の場合 100円未満切捨て、還付の場合は 1円単位
第3期分（申告時の納付・還付） = 申告納税額 − 予定納税額
```

**累進税率の扱い**：速算表は「境界を超えた部分にのみ高い税率」をかけた結果と同じになる。テストで境界の前後の税額が連続していることを確認している（例：課税所得 194.9万円→97,450円、195万円→97,500円）。

## 3-2. 給与所得（`salaryIncome`）

```
給与収入 ≤ 最低保障の区分上限  → 給与収入 − 最低保障額（令和7年分 65万円・190万円以下 / 令和8年分 74万円・220万円以下）
それ以外（660万円未満）       → 収入を4,000円単位に切り捨ててから計算（所得税法別表第五に合わせる）
  360万円以下: 収入×30%＋8万円 / 660万円以下: 収入×20%＋44万円 / 850万円以下: 収入×10%＋110万円 / 超: 195万円
合計所得金額 = max(0, 事業所得 ＋ 給与所得)   ※ 事業の赤字は給与所得と損益通算
```

## 3-3. 所得控除（`calcDeductions`）

所得税と住民税の控除額を並べて計算し、住民税の調整控除に使う「人的控除差額」も合わせて求める。

| 控除 | 所得税 | 住民税 | 人的控除差額 |
|---|---|---|---|
| 配偶者控除（本人900万円以下） | 38万（老人48万） | 33万（老人38万） | 5万（10万） |
| 配偶者控除（950万円以下 / 1,000万円以下） | 26万・13万（老人32万・16万） | 22万・11万（26万・13万） | 差額 |
| 配偶者特別控除 | 配偶者の所得が要件超〜133万円で段階的に減少 | 同左（最初の区分は100万円以下で33万） | 要件のすぐ上の区分のみ5万・3万 |
| 扶養控除 一般（16歳以上） | 38万 | 33万 | 5万 |
| 特定扶養（19〜22歳） | 63万 | 45万 | 18万 |
| 老人扶養（70歳以上） / 同居老親等 | 48万 / 58万 | 38万 / 45万 | 10万 / 13万 |
| 障害者 / 特別障害者 / 同居特別障害者 | 27万 / 40万 / 75万 | 26万 / 30万 / 53万 | 1万 / 10万 / 22万 |
| 寡婦 / ひとり親（本人500万円以下） | 27万 / 35万 | 26万 / 30万 | 1万 / 母5万・父1万 |
| 基礎控除 | 年度別の区分表 | 43万（2,400万円以下） | 5万 |

- 年齢は年末（12月31日）時点。扶養親族・同一生計配偶者の合計所得金額要件は令和7年分58万円、令和8年分62万円。
- 生命保険料控除（新契約）: 所得税 各区分最大4万円・合計12万円、住民税 各区分最大2.8万円・合計7万円（1円未満切上げ）。
- 地震保険料控除: 所得税 最大5万円、住民税 支払額の1/2・最大2.5万円。
- 医療費控除: 支払額 − 補てん額 − min(10万円, 総所得金額等×5%)、最大200万円。セルフメディケーション税制: 購入額 − 1.2万円、最大8.8万円。
- 寄附金控除（所得税）: min(寄附金, 総所得金額等×40%) − 2,000円。

## 4. 住民税（`calcResidentTax`）

```
基礎控除（住民税） = 43万円（合計所得 2,400万円以下）ほか区分表
生命保険料控除 = min(所得税の控除額, 7万円)   ※ 概算
課税所得 = max(0, 合計所得 − 所得控除合計) を 1,000円未満切捨て
調整控除（人的控除差額の合計を使う）
  課税所得 ≤ 200万円: min(差額合計, 課税所得) × 5%
  課税所得 > 200万円: max(差額合計 − (課税所得 − 200万円), 5万円) × 5%
  合計所得 > 2,500万円: 0
  市町村 3%・道府県 2% に按分
所得割 = (課税所得 × 6% − 調整控除3%分) 100円未満切捨て
       + (課税所得 × 4% − 調整控除2%分) 100円未満切捨て
均等割 = 市町村 3,000円 + 道府県 1,000円 + 森林環境税 1,000円（標準）
```

ふるさと納税（寄附金税額控除）:
  基本分 = (min(寄附金, 総所得金額等×30%) − 2,000円) × 10%
  特例分 = (寄附金 − 2,000円) × (90% − 所得税の限界税率×1.021)、所得割の20%が上限
  市町村 6/10・道府県 4/10 に按分して所得割から差し引く

未対応：非課税判定、超過課税、ふるさと納税以外の寄附金税額控除、住宅ローン控除の住民税分。

## 5. 国民健康保険料（`calcNhi`）

```
算定基礎額（旧ただし書き所得） = max(0, 総所得金額等 − 住民税の基礎控除)
各区分（医療・後期高齢者支援金・介護※・子ども子育て支援金）
  = min(算定基礎額 × 所得割率 + 均等割 × 人数 + 平等割, 賦課限度額)
合計 = 各区分の合計を 100円未満切捨て
※ 介護分は年度末時点で 40〜64歳の場合
```

- 料率は **自治体ごとに異なる**。利用者の入力を前提とし、未入力の場合は参考値（`SAMPLE_NHI_RATES`、特定の自治体の値ではない）で試算して警告を出す。
- 未対応：軽減（7割・5割・2割）、減免、子ども・子育て支援金分の既定値、年度途中の加入・脱退。
- 自治体の料率入力画面は第5段階で実装（DB 列 `nhi_rates` は作成済み）。

### 非課税の判定（第5段階）

```
人数 = 本人 ＋ 同一生計配偶者 ＋ 扶養親族（16歳未満を含む）
所得割:  総所得金額等 ≤ 35万円×人数 ＋ 10万円 ＋（扶養がいれば 32万円）
均等割:  総所得金額等 ≤ 級地別の額×人数 ＋ 10万円 ＋（扶養がいれば 級地別の加算）
         1級地 35万円・21万円 / 2級地 31.5万円・18.9万円 / 3級地 28万円・16.8万円
障害者・寡婦・ひとり親: 合計所得金額 135万円以下なら非課税
```

単身・1級地では合計所得45万円以下（令和9年度は給与収入119万円以下）が非課税。

### 国民健康保険料の軽減（第5段階）

```
判定所得 = 本人の総所得金額等 ＋ 他の加入者の所得
基準額   = 43万円 ＋ 10万円 ×（給与所得者等の数 − 1）
7割軽減: 判定所得 ≤ 基準額
5割軽減: 判定所得 ≤ 基準額 ＋ 31万円 × 加入者数
2割軽減: 判定所得 ≤ 基準額 ＋ 57万円 × 加入者数
軽減は均等割・平等割にのみかかり、所得割はかからない（令和8年度の基準）
```

## 6. 個人事業税（`calcBusinessTax`）

```
課税標準 = max(0, 青色申告特別控除前の所得 − 事業主控除 290万円) を 1,000円未満切捨て
税額 = 課税標準 × 税率（3% / 4% / 5%） を 100円未満切捨て
```

業種が法定業種に当たるかは都道府県が判定するため、税率は利用者が選択（未選択なら「計算不可」）。

## 7. 消費税（`calcConsumptionTax`）

- 免税事業者：0円
- 2割特例：売上（税込・税率10%）× 10/110 × 20%（100円未満切捨て）。令和8年分まで。
- 一般課税・簡易課税・軽減税率：未対応（計算不可と表示）

## 8. 年末予測（`forecastYearEnd`）

- 年初（年途中の開業は開業日）から基準日までの経過月数を日割りで計算。
- 年末予測 = 実績 + 月平均 × 残り月数。
- 精度の目安：経過 3か月未満 = 低、8か月未満 = 中、それ以上 = 高。
- 利用者が「年末までの残りの売上・経費の見込み」を入力した場合は、実績＋見込みを年末予測とする（空欄の項目は月平均）。

## 8-2. シミュレーション（`lib/simulation`）

- 変更前と変更後で `buildDashboard` を2回実行して比較する（税額は計算エンジンで計算し、AI による推測は行わない）
- 売上の増減・経費は年末予測に加える。控除の追加は申告設定を変更して計算する
- 備品の購入（`assetExpense`）: 10万円未満は全額、10〜20万円は一括償却（取得価額の1/3）を選択可、それ以外は定額法で使用開始月からの月数分
- 税金・保険料の負担 = 所得税等 ＋ 消費税 ＋ 翌年度の住民税・国保・事業税（1年分の所得にかかる合計）
- 手元に残る計算の変化 = 入ってくる／出ていくお金の変化（売上の増減 − 支出 − 備品の購入額 − 掛金 − 寄附） − 負担の変化

## 9. ダッシュボード集計（`buildDashboard`）

売上・経費の出どころ：

- その年の仕訳が1件以上あれば **帳簿の集計**（収益科目の合計・費用科目の合計）を使う
- なければ初期設定の **概算入力** を使い、その旨を警告で表示する
- 減価償却費は年額が決まっているため、月平均で延長せず年末予測の経費にそのまま加える
- 源泉徴収税額は、初期設定の入力（年間見込み）を優先し、未入力なら帳簿の入金記録（その年に入金された売上の源泉徴収税額）の合計を使う

税額を **税目別・対象年度別・納付時期別** の `TaxLine` に分ける。

| timing | 内容 | 例（2026年分） |
|---|---|---|
| `filing` | 確定申告時に精算 | 所得税等（年間・追加納付見込み）、消費税 |
| `next_fiscal_year` | 翌年度に支払う | 2027年度の住民税・国保・個人事業税 |
| `reserve` | 任意の取り置き | 第5段階 |

`kind` で **予測（forecast）／確定（confirmed）／納付済み（paid）** を区別する（現在はすべて予測）。

計算上の残額：

```
申告時の精算後 = 事業利益（年末予測）
               − 源泉徴収税額 − 予定納税額 − 申告時の追加納付（還付ならプラス）
               − 消費税（課税事業者の場合）
来年の税金も取り置いた場合 = 申告時の精算後 − 翌年度分（計算できたものの合計）
```

どちらも口座残高・自由に使えるお金ではない旨を画面に明記する。

## 9-2. 納付カレンダーと取り置き（`lib/schedule`）

- `buildSchedule`: ダッシュボードの計算結果から、確定申告（3月15日・振替納税は4月中旬の目安）・消費税（3月31日）・翌年の予定納税（申告納税額15万円以上で7月・11月に1/3ずつ）・翌年度の住民税（4回）・国保（設定した回数）・事業税（2回）を作る。年税額は2期目以降を100円単位にそろえ、端数を1期目に含める
- 通知書の金額があれば、同じ税目・年度の予測を置き換える（kind: confirmed）。納付済みの記録があれば kind: paid
- `reservePlan`: 未納・今後の支払いを納期限順に並べ、「その納期限までの累計 − 取り置き済み」を残り月数で割った値の最大値を毎月の取り置き目安とする（すべての納期限に間に合う最小の月額）

## 10. 新しい年度の追加手順

1. `rules/YYYY.ts` を作成し、公式資料で各値を確認。確認状況と出典を `notes` に記録。
2. `rules/index.ts` に登録。
3. `tax-engine.test.ts` に国税庁の計算例・検証済みケースを追加。
4. 確認が完了するまでバージョンに `provisional` を付ける。
5. 税理士等のレビュー後に `provisional` を外す。
