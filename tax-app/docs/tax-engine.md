# 税金計算エンジン設計書（tax-engine.md）

## 1. 方針

- 税金計算は AI による文章生成とは独立した、**テスト可能な純粋関数**として実装する（`src/lib/tax/`）。
- 対象年度ごとに税率・控除・適用条件を **税務ルール（`TaxRuleSet`）** として管理する（`src/lib/tax/rules/`）。
- 税目ごとにモジュールを分ける。
- 金額は円単位の整数。浮動小数の誤差を避けるため、率の掛け算は `multiplyRate`（10万分率の整数に直して計算）を使う。
- **公式資料で確認できない項目は推測で実装しない**。各ルール項目に確認状況を持たせ、画面に表示する。

### 確認状況（`VerificationStatus`）

| 値 | 意味 | 画面表示 |
|---|---|---|
| `verified` | 国税庁・自治体などの公式資料で確認済み | 公式資料で確認済み |
| `secondary_source` | 民間の解説資料等では確認したが、公式資料での最終確認が未了 | 公式資料で最終確認中 |
| `unverified` | 仮の値（自治体ごとに異なる等） | 仮の値 |
| `not_implemented` | 未対応（計算に含めていない） | 未対応 |

ルールのバージョンに `provisional` を含む年度は、ホーム画面に「税務ルールは確認中」と表示する。

## 3. 所得税（`calcIncomeTax`）

```
収入金額 − 必要経費 = 青色申告特別控除前の所得（profit）
青色申告特別控除 = min(控除額, profit)        ※ profit ≤ 0 なら 0
事業所得 = max(0, profit − 青色申告特別控除)    ※ 赤字は 0（繰越・損益通算は未対応）
合計所得金額 = 事業所得                         ※ 他の所得は未対応
基礎控除 = 区分表（合計所得金額で判定）
所得控除合計 = 社会保険料 + 小規模企業共済等掛金 + 生命保険料控除 + その他 + 基礎控除
課税所得 = max(0, 合計所得 − 所得控除合計) を 1,000円未満切捨て
基準所得税額 = 課税所得 × 税率 − 速算表の控除額（1円未満切捨て）
復興特別所得税 = 基準所得税額 × 2.1%（1円未満切捨て）
所得税及び復興特別所得税 = 基準所得税額 + 復興特別所得税
申告納税額 = 上記 − 源泉徴収税額
             → 納付の場合 100円未満切捨て、還付の場合は 1円単位
第3期分（申告時の納付・還付） = 申告納税額 − 予定納税額
```

**累進税率の扱い**：速算表は「境界を超えた部分にのみ高い税率」をかけた結果と同じになる。テストで境界の前後の税額が連続していることを確認している（例：課税所得 194.9万円→97,450円、195万円→97,500円）。

### 基礎控除の区分表

| 合計所得金額 | 令和7年分 | 令和8年分（※要確認） |
|---|---|---|
| 132万円以下 | 95万円 | 104万円 |
| 132万円超 336万円以下 | 88万円 | 104万円 |
| 336万円超 489万円以下 | 68万円 | 104万円 |
| 489万円超 655万円以下 | 63万円 | 67万円 |
| 655万円超 2,350万円以下 | 58万円 | 62万円 |
| 2,350万円超 2,400万円以下 | 48万円 | 48万円 |
| 2,400万円超 2,450万円以下 | 32万円 | 32万円 |
| 2,450万円超 2,500万円以下 | 16万円 | 16万円 |
| 2,500万円超 | 0円 | 0円 |

※ 令和8年分は令和8年度税制改正（本則62万円＋令和8・9年分の特例加算）について民間の解説資料で確認した値。**国税庁の公式資料で最終確認が必要**（`secondary_source`）。

## 4. 住民税（`calcResidentTax`）

```
基礎控除（住民税） = 43万円（合計所得 2,400万円以下）ほか区分表
生命保険料控除 = min(所得税の控除額, 7万円)   ※ 概算
課税所得 = max(0, 合計所得 − 所得控除合計) を 1,000円未満切捨て
調整控除（本人の基礎控除の人的控除差額 5万円のみ考慮）
  課税所得 ≤ 200万円: min(5万円, 課税所得) × 5%
  課税所得 > 200万円: max(5万円 − (課税所得 − 200万円), 5万円) × 5%
  合計所得 > 2,500万円: 0
  市町村 3%・道府県 2% に按分
所得割 = (課税所得 × 6% − 調整控除3%分) 100円未満切捨て
       + (課税所得 × 4% − 調整控除2%分) 100円未満切捨て
均等割 = 市町村 3,000円 + 道府県 1,000円 + 森林環境税 1,000円（標準）
```

未対応：非課税判定、配偶者・扶養の人的控除差額、超過課税、ふるさと納税などの税額控除。

## 5. 国民健康保険料（`calcNhi`）

```
算定基礎額（旧ただし書き所得） = max(0, 総所得金額等 − 住民税の基礎控除)
各区分（医療・後期高齢者支援金・介護※・子ども子育て支援金）
  = min(算定基礎額 × 所得割率 + 均等割 × 人数 + 平等割, 賦課限度額)
合計 = 各区分の合計を 100円未満切捨て
※ 介護分は年度末時点で 40〜64歳の場合
```

- 料率は **自治体ごとに異なる**。利用者の入力を前提とし、未入力の場合は参考値（`SAMPLE_NHI_RATES`、特定の自治体の値ではない）で試算して警告を出す。
- 未対応：軽減（7割・5割・2割）、減免、子ども・子育て支援金分の既定値、年度途中の加入・脱退。
- 自治体の料率入力画面は第5段階で実装（DB 列 `nhi_rates` は作成済み）。

## 6. 個人事業税（`calcBusinessTax`）

```
課税標準 = max(0, 青色申告特別控除前の所得 − 事業主控除 290万円) を 1,000円未満切捨て
税額 = 課税標準 × 税率（3% / 4% / 5%） を 100円未満切捨て
```

業種が法定業種に当たるかは都道府県が判定するため、税率は利用者が選択（未選択なら「計算不可」）。

## 7. 消費税（`calcConsumptionTax`）

- 免税事業者：0円
- 2割特例：売上（税込・税率10%）× 10/110 × 20%（100円未満切捨て）。令和8年分まで。
- 一般課税・簡易課税・軽減税率：未対応（計算不可と表示）

## 8. 年末予測（`forecastYearEnd`）

- 年初（年途中の開業は開業日）から基準日までの経過月数を日割りで計算。
- 年末予測 = 実績 + 月平均 × 残り月数。
- 精度の目安：経過 3か月未満 = 低、8か月未満 = 中、それ以上 = 高。
- 第2段階で月別実績、第6段階で今後の売上・経費の手入力補正を追加。

## 9. ダッシュボード集計（`buildDashboard`）

税額を **税目別・対象年度別・納付時期別** の `TaxLine` に分ける。

| timing | 内容 | 例（2026年分） |
|---|---|---|
| `filing` | 確定申告時に精算 | 所得税等（年間・追加納付見込み）、消費税 |
| `next_fiscal_year` | 翌年度に支払う | 2027年度の住民税・国保・個人事業税 |
| `reserve` | 任意の取り置き | 第5段階 |

`kind` で **予測（forecast）／確定（confirmed）／納付済み（paid）** を区別する（現在はすべて予測）。

計算上の残額：

```
申告時の精算後 = 事業利益（年末予測）
               − 源泉徴収税額 − 予定納税額 − 申告時の追加納付（還付ならプラス）
               − 消費税（課税事業者の場合）
来年の税金も取り置いた場合 = 申告時の精算後 − 翌年度分（計算できたものの合計）
```

どちらも口座残高・自由に使えるお金ではない旨を画面に明記する。

## 10. 新しい年度の追加手順

1. `rules/YYYY.ts` を作成し、公式資料で各値を確認。確認状況と出典を `notes` に記録。
2. `rules/index.ts` に登録。
3. `tax-engine.test.ts` に国税庁の計算例・検証済みケースを追加。
4. 確認が完了するまでバージョンに `provisional` を付ける。
5. 税理士等のレビュー後に `provisional` を外す。
