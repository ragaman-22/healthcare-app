# 専門家（税理士等）レビュー依頼書（expert-review.md）

公開前に、税理士等の専門家に確認していただきたい事項をまとめたものです。各項目の「確認結果」欄に記入してください。

## 1. レビューの進め方

1. デモ環境（`ALLOW_DEMO_MODE=true` の検証用環境）または検証用アカウントで、実際に操作していただく
2. `docs/verification/income-tax-cases.md` の照合表を、国税庁「確定申告書等作成コーナー」の結果と照合していただく
3. 本書の各項目に確認結果・指摘を記入していただく
4. 指摘は開発側で修正するか、「未対応」として画面に明示する

## 5. 未対応として明示している項目

画面上で「未対応」「対象外」と表示し、申告書を完成扱いにしない項目です。対応の優先度について意見をください。

- 給与以外の所得（年金・不動産・株式・雑所得など）、所得金額調整控除、特定親族特別控除、勤労学生控除
- 純損失の繰越控除・損益通算（給与との通算は対応済み）、第三表・第四表
- 住宅ローン控除などの税額控除、生命保険料の旧契約
- 消費税の一般課税・簡易課税・申告書、中間申告
- 棚卸・家事消費・専従者給与・貸倒引当金、地代家賃などの内訳書
- 少額減価償却資産の特例、定率法
- e-Tax 提出
